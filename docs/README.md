PRD와 유저 플로우는 2026-10-03 기준 코드에서 작성했다. 과거 단계 설명보다 현재 구현을 우선하고, UX 지침의 목표와 구현 상태를 구분했다. 운영 기본값·권한·기능 활성 여부는 운영 환경의 확인이 필요하다.
