# 교내 사용 경험 개선 — 2026-10-04

제품 분석에서 제안한 6개 항목을 구현했다. 실제 학생의 활성화·재방문 증가를 확인한 기록은 아니며, 로컬 구현과 검증 기록이다.

후속 요청으로 운영진방의 실제 계정 삭제와 복구 흐름을 추가했다. 아래의 삭제 요청 범위는 첫 구현 당시 기록이며 현재 처리는 [계정 삭제 운영 기록](./ACCOUNT-DELETION-2026-10-04.md)을 따른다.

| 항목 | 구현 |
|---|---|
| 다른 탭에서 매칭 유지 | `Seeker`를 앱 레이아웃의 Svelte context로 공유한다. 편지·프로필 탭에 대기와 취소를 표시한다. 홈의 목록 중복 구독을 제거했다. 계정 변경 시 이전 응답을 폐기하고 새 계정에 취소 RPC를 보내지 않는다. 앱 숨김 시 기존 폴링 중단·TTL 동작은 유지한다. 실행되지 않던 서버 취소 RPC를 실제로 실행하고, 취소 직후 다시 찾는 요청은 이전 취소가 끝난 뒤 보낸다. |
| 설치 전 체험 | 공개 `/welcome`에서 가상 대화·편지를 눌러 보고 익명 범위를 확인한다. `/install`에서 연결한다. 샘플은 인증·DB·AI 요청을 보내지 않는다. 실제 학생 기능의 설치·인증 가드는 유지한다. |
| 선호 직접 선택 | 신규 온보딩에서 성별을 골라도 이성 선호를 자동 선택하지 않는다. 성별을 다시 바꿔도 직접 고른 선호는 유지한다. 기존 계정의 선호는 변경하지 않는다. |
| 익명 범위 안내 | 공개 체험·온보딩·대화 시작부·편지 선택/작성에 안내를 추가했다. 연장 동의 직전 공개 항목과 입력 값 또는 등록 학년을 보여준다. 권한 있는 운영자의 신원·내용 열람과 추정 가능성을 설명한다. |
| AI 직접 선택 | 운영 설정이 켜졌을 때 대기 20초 후 선택 버튼을 표시한다. 클릭 전 AI 세션 생성 없음. AI 대화를 닫아도 사람 찾기를 유지하며 새 매칭 시 대화방으로 이동한다. |
| 계정 삭제 요청 | `/settings/delete`에서 설명 확인·선택 메모·접수·내역·운영진 답변·조회/전송 재시도를 제공한다. 기존 `account` 문의로 접수하고 관리자 문의 목록에도 구분 표시한다. 답변 도착을 삭제 완료로 표시하지 않는다. |

**삭제 요청의 범위**

기존 인증된 `send_inquiry`와 본인 요청만 조회하는 `my_inquiries`를 사용한다. SQL·마이그레이션·접근 권한 변경은 없다. 본문에 이름·학번·이메일·비밀번호를 추가하지 않으며 선택 설명을 포함해 1,000자 상한을 지킨다. 기존 미답변 3건·최근 하루 5건 제한을 적용하고 실패 이유를 안내한다. 조회된 미답변 삭제 요청이 있으면 화면에서 재접수를 막는다.

기존 문의 조회는 최근 20건이므로 삭제 요청 화면도 그 범위에서 내역을 보여준다. 전체 이력 보관이나 서버 차원의 삭제 요청 고유성 보장은 추가하지 않았다. 실제 계정 삭제·세션 폐기·상대에게 전달된 정보·신고 증거·백업·내보낸 파일의 처리와 운영진 역할은 기존 운영 절차에 따른다. 요청 철회와 추가 질문은 계정 문의로 연결한다.

**검증**

- `npm run test:unit`: 통과. 삭제 요청 구분/본문 상한과 계정 전환 후 늦은 매칭 응답 폐기 검증을 추가했다.
- 최종 `npm run check`: 오류 0·경고 0.
- 최종 `npm run build`: Cloudflare 어댑터 출력까지 성공. 첫 시도의 출력 폴더 잠금은 이전 미리보기 서버를 종료한 뒤 해소했다.
- 최종 `npm run test:chat`: 124개 통과. 실제 thenable 취소 실행·다시 찾기 순서·계정 전환 시 늦은 응답 폐기를 검증했다.
- 브라우저 검사 423개 통과: `product` 36, `back` 113, `ux` 31, `bot` 36, `letters` 207. 신규 흐름과 기존 뒤로가기·편지·AI 흐름을 확인했다. 공개 체험 화면은 320·390·560px 너비에서 가로 넘침이 없다.
- 브라우저 검증은 가짜 Supabase 응답과 개발 미리보기를 사용한다. 실제 학생·운영진에게 문의를 보내지 않는다.
- 운영 배포·실제 AI 모델 호출·실기기 푸시·학생 인터뷰는 수행하지 않는다.
